# snowScatt
[SnowScatt](https://github.com/OPTIMICe-team/SnowScatt) is an Open Source
Python package to compute scattering and microphysical properties of
snowflakes ensambles. Use Self-Similar Rayleigh-Gans Approximation and
snowflake aggregation models
